# Domain docs

Layout: single-context. `GLOSSARY.md` at the repository root holds the domain language; `docs/adr/` holds decisions. `CONTEXT.md` explains how the concepts relate and is the first read for a new agent.

Consumer rules: read `GLOSSARY.md` before naming anything; when a term is sharpened or added during work, update `GLOSSARY.md` in the same change; offer an ADR only when a decision is hard to reverse, surprising without context and the result of a real trade-off.
